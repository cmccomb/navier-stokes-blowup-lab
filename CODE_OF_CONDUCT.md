# Code of conduct

We want this project to be a rigorous, welcoming place for mathematical and
computational collaboration. Be respectful, critique ideas and evidence rather
than people, state uncertainty plainly, and give credit for others' work.

Harassment, discriminatory language, personal attacks, and deliberate
misrepresentation of results are not acceptable. Maintainers may edit, remove,
or reject contributions that violate these expectations. Report conduct issues
privately to the repository owner through their GitHub profile.
