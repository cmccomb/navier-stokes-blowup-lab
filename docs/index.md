# Documentation

This directory is the authoritative technical documentation for the
Navier–Stokes Blow-up Lab. The root README is intentionally limited to project
orientation and a smoke-run command.

## Guides

- [Model and numerical method](model.md) explains the implemented surrogate,
  governing equations, discretization, diagnostics, and interpretation limits.
- [Experiment runbook](running.md) contains reproducible commands for local,
  high-resolution, control, study, validation, and publication workflows.
- [Reproduction target](reproduction.md) defines the fidelity gates for a
  controlled finite truncation of the analytical construction.
- [Results](results.md) is the full numerical record, including superseded
  studies and negative findings.

Repository policy and review expectations live in
[CONTRIBUTING.md](../CONTRIBUTING.md). The public
[current-best results page](https://cmccomb.com/navier-stokes-blowup-lab/)
intentionally shows less than these documents.
